# React Dev Week 2 - React App

## Guided Learning Activity: Creating Your First React App with TypeScript and Vite

### Goal

Build a simple React application using TypeScript and Vite. The application demonstrates how to create a custom React component and style it using CSS.

## Technologies Used

- React
- TypeScript
- Vite
- CSS
- Git and GitHub

## Features

- React application created with Vite
- Custom `MyComponent` component
- TypeScript used for the React components
- CSS styling separated into its own file
- Responsive centered layout
